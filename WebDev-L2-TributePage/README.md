# WebDev-L2-TributePage 🇮🇳

A clean, responsive tribute web page dedicated to **Dr. A. P. J. Abdul Kalam** (1931–2015) — the revered scientist, "Missile Man of India," and 11th President of India.

Developed as part of the **Oasis Infobyte Web Development and Designing Internship (OIBSIP)** — **Level 2, Task 2**.

---

## ✨ Features

- **Semantic HTML5 & Pure CSS3**: Built entirely without JavaScript or external CSS frameworks.
- **Hero Header & Profile Frame**: Elegant header displaying Dr. Kalam's name, one-line tagline, and a styled glassmorphic image frame for `<img src="images/kalam.jpg">`.
- **Original Biography Section**: Four thoughtfully structured, paraphrased narrative blocks chronicling his humble beginnings, space & defense leadership, presidential tenure, and dedication to teaching.
- **Milestones & Achievements Timeline**: A styled, ordered timeline list presenting major historical milestones (1931, 1960, 1980, 1980s, 1997, 1998, 2002, 2015).
- **Featured Quote Banner**: A distinct, warm quote block highlighting his famous quote on dreaming and hard work.
- **Typography & Color Hierarchy**:
  - **Serif Font**: *Playfair Display* for headings and quotes.
  - **Sans-Serif Font**: *Outfit* for crisp body text readability.
  - **Diverse Section Backgrounds**: Gradient navy hero, warm amber quote section, crisp slate biography, and dark navy timeline cards.
- **Responsive Layout**: Designed using CSS Grid and Flexbox for seamless adaptation across mobile, tablet, and desktop screens.

## 🚀 How to Run Locally

1. **Navigate to the Directory**:
   Open the `WebDev-L2-TributePage` folder in your file manager or code editor.

2. **Open the Page**:
   - Double-click `index.html` to launch it directly in any browser (Chrome, Firefox, Edge, Safari, Brave).
   - Or open using a local live server:
     ```text
     http://localhost:3000/WebDev-L2-TributePage/
     ```
