## ✨ Design & Feature Enhancements

1. **Hero Section with Visual Polish:**
   - Soft radial gradient glow behind the avatar (`.avatar-glow`).
   - Smooth **CSS-only floating keyframe animation** on the avatar circle (`@keyframes floatAvatar`).
   - Initials placeholder `"AS"` styled with glowing gradient border without needing external image assets.
   - **Hero Stats Row:** Quick-glance metrics (`3+ Projects`, `6 Core Skills`, `Final Year`).

2. **Categorized & Grouped Skills:**
   - Skills grouped cleanly under:
     - **Languages** (Python, HTML/CSS/JavaScript, Kotlin, MATLAB)
     - **Frameworks & Backend** (Flask)
     - **Databases & Storage** (MongoDB)
   - Interactive cards with a **hover lift effect** (`transform: translateY(-6px)`) and glowing accent borders.

3. **Expanded Project Showcase:**
   - Larger cards with tech-stack pill badges (`Python`, `Flask`, `MongoDB`, `JavaScript`, etc.).
   - Hover lift and shadow elevation effects.
   - Prominent **"View on GitHub"** button links.

4. **Sticky Navigation & Pure CSS Highlighting:**
   - Fixed/Sticky blur header navigation with CSS active/hover state feedback.
   - Smooth anchor navigation across all sections (`scroll-behavior: smooth`).

5. **Footer with Social Links:**
   - Social profile badges linking directly to GitHub, LinkedIn, and Email.

6. **Design System & Responsiveness:**
   - Unified color tokens defined with CSS variables (`:root`).
   - Google Font (`Inter`).
   - Fully responsive layout across mobile, tablet, and widescreen displays using Flexbox and Grid.
